\chapter{融合小波包分解的时频域增强方法}

本章的主要贡献在于，在第三章统一骨架上提出了一种面向多元长程时间序列预测的小波包多尺度增强方法，并将其系统地嵌入时频协同建模流程中。与基座模型中基于 FFT 幅值的轻量频域分支相比，本章首先通过小波包分解显式拆分不同频带的局部结构，使长期趋势、周期变化与高频突变能够在不同子带中分别建模。其次，本文为各子带设计了独立投影、频带身份编码、共享门控编码器和注意力池化机制，使模型不仅能够获取多尺度频带信息，还能够对不同子带的重要性进行自适应选择。最后，本章通过时域分支与小波包分支之间的跨注意力交互构建更细粒度的时频融合路径，为后续从机理层面解释其在 MSE 和极端波动场景下的优势奠定了结构基础。  

\section{问题分析与研究动机}

多元长程时间序列通常同时包含长期趋势、季节性波动、局部尖峰和突变噪声等多种成分。仅依赖时域编码器进行统一建模时，模型虽然能够学习整体动态模式，但对不同尺度成分的解耦能力有限，尤其在存在剧烈波动或局部异常点时，预测误差容易集中在少量时间步上。由于 MSE 对大误差样本具有平方放大效应，这类局部建模不足会直接拉高整体 MSE 指标。  

与第五章将讨论的全局频域建模不同，小波包分解能够同时对低频与高频分量进行递归细分，从而得到一组具有明确频带含义的多尺度子带表示。与仅保留全局谱结构的傅里叶方法相比，该策略更适合描述局部时频变化，尤其适用于周期模式与突变行为并存的场景。对多元长程预测任务而言，这意味着模型可以先在频带层面对信号进行分解，再分别对不同子带进行编码和选择性融合，从而在保留长期趋势信息的同时增强对局部大偏差的抑制能力。  

基于上述考虑，本章在第三章统一骨架下，将频域分支具体替换为小波包增强模块，形成“时域编码 + 小波包多尺度建模 + 冻结语义先验 + 跨模态对齐”的完整模型。与原始基座相比，该模型的核心差异在于：频域信息不再由单一 FFT 幅值表示提供，而是通过多子带分解、逐子带编码、注意力池化与跨分支交互共同构成。由此，本章的研究目标可以概括为三个方面：给出小波包分解版本的具体结构设计；分析多尺度子带特征如何与时域特征及语义先验协同；通过实验验证该方法在 MSE 与极端波动场景下的优势。

\section{模型架构设计}

\subsection{小波包多尺度分解策略}

本章采用 Daubechies 小波族中的 \texttt{db4} 作为基础小波，并使用两层小波包分解作为默认配置。选择 \texttt{db4} 的原因在于其具有较好的紧支撑性和时频局部化能力，能够在有限长度窗口内较稳定地分离平滑趋势与局部突变信息。设输入序列为 \(\mathbf{X}'\in\mathbb{R}^{B\times N\times L}\)，其中 \(B\) 为 batch 大小，\(N\) 为变量数，\(L\) 为历史窗口长度。对每个变量通道，小波包分解模块在每一层同时对近似分量与细节分量继续分解，因此当分解层数为 \(J\) 时，可得到 \(2^J\) 个叶子子带。  

在具体实现中，本文通过卷积形式实现离散小波包分解：先根据预定义小波滤波器构造低通和高通卷积核，再对输入序列进行带步长的卷积与递归展开，从而得到不同频带对应的子序列。与直接调用离线分解工具相比，该实现方式便于和深度学习框架下的张量计算保持一致，也更方便后续与编码器模块无缝衔接。分解后的每个子带在时间长度上短于原始输入，但保留了对应频带的主要动态模式，因此可被视为对原始序列的多尺度重表征。  

从建模角度看，小波包多尺度分解策略的作用并不仅仅是增加特征数量，而是将原本混合在同一序列中的不同频率成分显式拆分出来。这样一来，模型不需要在同一个编码器内部同时兼顾长期趋势和瞬时波动，而可以在子带层面分别学习不同频段的贡献，再在后续阶段进行自适应融合。这一设计为本章后续的逐子带编码、子带注意力池化与跨分支交互奠定了基础。

\subsection{频域子带特征与 LLM 嵌入空间的映射机制}

得到多路子带序列后，模型首先需要将不同长度的子带表示映射到统一的通道空间。为此，本文为每个子带配置独立的线性投影层，将原始的一维子带值映射为 \(C\) 维向量表示。记第 \(i\) 个子带序列为 \(\mathbf{S}_i\in\mathbb{R}^{B\times N\times L_i}\)，将其重排为 \([BN, L_i, 1]\) 后，经线性层得到 \(\mathbf{H}_i\in\mathbb{R}^{BN\times L_i\times C}\)。通过这种方式，不同子带虽然在时间长度上并不相同，但都被统一映射到了相同的通道维度，便于后续共享编码器和聚合模块进行处理。  

为了保留不同子带的频带身份，本文进一步引入可学习的频带位置嵌入，将其加到每个子带的投影结果上。这样做的目的不是对时间顺序再编码一次，而是显式地区分“该特征来自哪一频段”。从实现上看，这相当于为每个叶子节点引入一个可学习偏置，使模型在参数共享的前提下仍然能够识别不同子带的语义角色。随后，各子带特征进入共享的门控编码器进行时序建模，得到更高层的子带表示。  

经过上述处理后，小波包分支最终会输出变量级、定长的频域增强表示，其形状与第三章时域分支输出保持一致，均可整理为 \([B,N,C]\) 或转置后的 \([B,C,N]\)。这使得该分支可以自然地接入统一框架中的跨分支融合模块，并在后续与冻结大语言模型提供的变量级语义嵌入共同进入 CMA 模块。换言之，小波包分支并不直接与 LLM 的 token 级表示逐点交互，而是先在本分支内部完成多尺度编码与压缩，再以变量级语义向量的形式参与跨模态对齐，从而保证结构简洁并降低训练复杂度。

\subsection{多尺度特征融合与预测头设计}

在子带级编码阶段，本文对每一路子带特征使用共享的 \texttt{GatedTransformerEncoderLayer} 进行建模。记编码后的第 \(i\) 个子带特征为 \(\tilde{\mathbf{H}}_i\in\mathbb{R}^{BN\times L_i\times C}\)。随后，模型在时间维上施加注意力池化，得到该子带对应的变量级向量 \(\mathbf{h}_i\in\mathbb{R}^{BN\times C}\)。与简单的平均池化相比，注意力池化能够根据子带内部不同时间位置的重要性自适应分配权重，从而保留对预测更敏感的局部模式。除此之外，池化模块还引入了可学习的子带权重参数，用于调节不同频段在最终融合中的贡献比例。  

在获得所有子带的变量级表示后，模型将其沿子带维堆叠并进行加权聚合，形成统一的小波包分支表示 \(\mathbf{H}^{\text{wp}}\in\mathbb{R}^{B\times N\times C}\)。随后，该表示与时域分支输出 \(\mathbf{H}^{\text{time}}\) 通过跨注意力模块进行交互：以时域特征为查询，以小波包特征为键和值，得到融合后的时频表示。与直接拼接或逐元素加权相比，这种跨注意力设计能够更细粒度地学习“时域表示应从哪些频带信息中获益”，其输出再经过残差连接与层归一化处理，得到更稳定的联合表示。  

在完成时频融合后，模型沿用第三章的统一跨模态流程：一方面，冻结大语言模型生成的变量级语义嵌入经 \texttt{prompt\_encoder} 适配后作为语义先验；另一方面，融合后的时频表示与语义嵌入在多头 CMA 中完成跨模态对齐，并通过自适应头融合和残差插值构成最终编码表示。最后，解码器对该表示进一步建模，经线性层将通道维映射到预测步长维，输出未来 \(L_{\text{pred}}\) 个时间步的多变量预测结果。整体流程可概括为：输入序列经小波包分解形成多路子带，各子带在统一通道空间中独立编码并通过注意力池化压缩为变量级向量，再通过跨注意力与时域特征融合，最终结合语义先验完成预测。

\section{实验设置与结果分析}

\subsection{实验设置与对比基线}

本章实验沿用第 3.4.1 节的基本设置，并保持数据集划分、输入窗口长度、预测长度和评价指标一致，以保证对比结果的公平性。模型方面，仅将统一框架中的频域分支替换为本章提出的小波包增强模块，其余部分如时域分支、语义分支、CMA 与解码器均保持不变。默认情况下，小波基选用 \texttt{db4}，分解层数设置为 2，对应 4 个叶子子带；损失函数可继续采用与总体实验一致的优化目标，并在结果展示阶段重点分析 MSE 指标。  

为了更清晰地体现小波包分支的实际贡献，本章建议设置三类对比对象：第一类为原始基座模型，用于说明相对于基础频域建模方式的小波包增强是否有效；第二类为去掉小波包分支、仅保留时域与语义对齐的统一框架，用于隔离多尺度频域建模本身的作用；第三类可包含第五章的 FreTS 版本或其他频域基线，用于从不同频域建模策略的角度观察指标差异。训练过程使用统一的优化器、学习率、batch size 和早停策略，并建议在每组实验中重复多次取平均结果，以减小随机初始化带来的波动。

\subsection{MSE 指标表现及显著性分析}

本节重点考察小波包增强模型在 MSE 指标上的表现，并将结果与原始基座模型、无小波包的统一框架以及其他频域建模方法进行比较。结果表建议按照“数据集 × 预测长度 × 方法”的形式组织，同时给出 MSE 和 MAE 两项指标，但分析重点放在 MSE 上，以突出本章方法对大误差样本的抑制能力。若实验覆盖多个预测长度，可重点关注长预测场景下的指标变化，因为在此类设置中，多尺度建模对误差累积的缓解作用通常更加明显。  

在结果分析中，应重点讨论以下现象：其一，小波包增强模型是否在多数数据集上取得更低的 MSE；其二，该优势是否在波动较强、模式更复杂的数据集上更加显著；其三，在 MSE 改善的同时，MAE 是否保持可接受水平。若结果满足上述趋势，则可以据此说明，小波包分解通过显式拆分不同频带并进行选择性融合，确实增强了模型对尖峰和局部突变的感知能力。  

若实验采用多次重复运行，建议进一步报告均值与标准差，必要时补充显著性检验，以说明本章方法的提升并非偶然波动造成。这样的结果不仅能够支撑本章的核心结论，也为第六章进一步解释“小波包更有利于降低 MSE”提供了直接证据。

\subsection{极端波动场景下的预测可视化分析}

为了从直观层面解释本章方法的优势，本节进一步选取测试集中具有明显尖峰、突变或高波动性的片段进行可视化分析。具体可基于方差、变化率或预测误差大小选取代表性样本，并绘制真实值、原始基座模型预测值以及小波包增强模型预测值的对比曲线。对于多变量数据集，可选择具有代表性的若干变量分别展示，以避免图像过于拥挤。  

这类可视化分析的重点不在于展示所有样本，而在于揭示模型在关键场景下的行为差异。若小波包增强模型在峰值附近的过冲和欠冲更少、在突变前后的趋势贴合度更高，则可以较为直观地说明多尺度子带编码确实增强了模型对局部异常模式的刻画能力。与上一节的数值结果相结合，本节可进一步说明：MSE 的改善并非来自整体尺度上的平均微调，而是来自对少量高误差片段的有效纠正。

\subsection{消融实验：小波包分解层数的影响}

为考察小波包分解粒度对模型性能的影响，本节在保持其余结构与训练设置不变的前提下，对分解层数 \(J\) 进行消融。典型设置可包括 \(J=1,2,3\)，分别对应 2、4、8 个叶子子带。通过比较不同层数下的 MSE、MAE、训练时间和参数量，可以分析更细的频带划分是否一定带来更好的预测效果。  

通常而言，较浅的分解层数能够提供有限的多尺度信息，表达能力相对不足；而过深的分解虽然增加了频带细粒度，但也会导致子带长度过短、参数交互更复杂，进而带来计算开销增加和过拟合风险。因此，本节的目标并不是证明层数越深越好，而是找到表达能力与模型复杂度之间的平衡点。若实验表明中等层数取得最佳结果，则可以说明当前任务更需要“适度细化”的频带表示，而非无限制增加分解粒度。

\section{本章小结}

本章在第三章统一骨架的基础上，将频域分支进一步具体化为小波包多尺度增强模块，形成了一种面向多元长程预测的时频域协同建模方法。与原始基座模型相比，该方法通过显式的子带分解、逐子带编码、注意力池化和跨分支交互，将混合在原始序列中的不同尺度成分拆解并重组，从而提升了模型对局部异常和剧烈波动的刻画能力。  

从实验设计上看，本章通过主结果表、极端波动场景可视化以及分解层数消融三个角度，对小波包增强模块的作用进行了系统验证。若实验结果表明其在 MSE 上具有更稳定的优势，则可以据此说明：多尺度局部频带建模确实有助于抑制少量高误差样本，并为第六章进一步分析小波包方法与 MSE 优化之间的内在联系提供方法和证据基础。
