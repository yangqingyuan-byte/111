\chapter{总结与展望}

\section{研究工作总结}
多元长程时间序列预测的关键在于同时刻画长期趋势、局部波动与跨变量相关关系。针对现有方法在时频协同建模不足、语言模型语义先验难以稳定引入等问题，本文围绕统一预测骨架、局部多尺度频域增强和全局频域增强三条主线展开研究，形成了统一骨架下的两类频域增强研究框架。

首先，本文构建了融合时域建模、基础频域表示与冻结语义先验的统一预测骨架。第三章在时域主干之上引入由 Qwen3-0.6B 生成的语义嵌入，并通过轻量适配器、步长感知门控融合与跨模态注意力对齐实现多源信息协同建模。实验结果表明，Qwen3 语义先验与门控注意力机制能够在统一框架下带来较一致的性能改进，并为后续频域增强模块的对比实验提供统一接口。

其次，本文提出了融合小波包分解的局部多尺度频域增强方法。第四章通过可学习小波包分解、子带独立映射、共享编码器和注意力池化，将原始序列拆解为具有明确频带语义的局部多尺度表示，从而增强模型对峰谷变化、突变片段和复杂局部波动的刻画能力。实验结果表明，该方法在以 MSE 为代表、对大误差更敏感的评价条件下，在当前公开基准上呈现较一致优势，说明局部多尺度频域建模有助于抑制高误差样本对整体平方误差的放大作用。

再次，本文提出了融合频域前馈网络的全局频域增强方法。第五章基于 FreTS 思路，通过复数频谱建模、频域稀疏化和步长感知门控融合，在统一框架下强化模型对全局周期结构和整体平均偏差的建模能力。与第四章方法相比，该方案更强调从整体频谱中提取长期稳定模式。主实验、消融实验和参数敏感度实验表明，融合频域前馈网络的全局频域增强方法在平均误差控制和长期趋势刻画方面表现较好。

综合全文研究可得到如下结论：其一，冻结大语言模型语义先验只有在合理的适配与跨模态对齐机制支持下，才更有可能提升时间序列预测性能；其二，显式引入频域信息有助于改善长程预测效果，但局部多尺度频域建模与全局频域建模的增益侧重点不同，前者更适合处理局部异常与高误差样本，后者更适合建模整体周期结构、长期趋势与平均误差；其三，在统一骨架下融合语义先验与频域增强策略，能够在保持结构可解释性的同时获得较好的预测精度，为大语言模型在多元时间序列预测中的应用提供了可行的研究路径。

\section{研究不足与局限性}
尽管本文围绕统一骨架、局部多尺度频域增强和全局频域增强进行了较为系统的研究，但仍存在若干局限。

首先，在数据层面，本文实验主要基于 ETT、Weather、ILI 和 Exchange 等公开基准数据集。尽管这些数据集覆盖了工业负荷、气象、公共卫生和金融等典型场景，但与真实业务环境相比，其数据规模、缺失模式、采样不均匀性和概念漂移程度仍较为有限，因此本文方法在更复杂真实场景中的泛化能力仍有待进一步验证。

其次，在模型层面，本文采用 Qwen3-0.6B 作为冻结语义编码器，重点验证了在冻结语言模型主体条件下引入语言模型先验的有效性，但尚未系统比较更大规模语言模型、领域专用模型以及不同冻结或参数高效微调策略对时序建模的影响。同时，第四章的小波包增强方法与第五章的 FreTS 增强方法仍属于分别设计和验证的两条频域路线，二者在统一训练框架下的动态组合、联合优化与输入依赖选择机制尚未展开。

最后，在评价与应用层面，本文主要采用 MSE 与 MAE 作为核心评价指标，并据此分析两类频域增强方法的适用场景。然而，真实业务中往往还需要关注峰值误差、区间预测质量、风险成本或下游决策损失，因此仅依赖 MSE 与 MAE 仍不足以完全刻画模型的业务适配性。此外，本文尚未对推理时延、显存占用和部署开销进行系统评估，因此当前结论更适用于离线预测与方法比较场景。

\section{未来研究方向}
针对上述局限，未来可从以下几个方面进一步拓展。

首先，可以研究更加自适应的频域增强与模型选择机制。本文已经表明局部多尺度频域建模与全局频域建模在不同数据特性和误差指标下各具优势，因此后续可进一步设计输入依赖的选择策略，根据频谱熵、波动强度与趋势稳定性等统计特征，在小波包增强与频域前馈增强之间进行动态切换或加权融合，以降低人工选择成本。

其次，可以进一步探索更大规模或更具领域知识的大语言模型与时序建模的结合方式。未来可在保持统一骨架设计思想的前提下，研究更高参数规模模型、领域适配模型以及参数高效微调策略在时间序列任务中的适用性，并分析语言模型规模、语义质量与训练代价之间的平衡关系。同时，也可结合文本描述、事件知识或外部检索信息，构建更丰富的时序--语义联合建模框架。

再次，可以将当前方法推广到更加复杂的数据形式与下游任务。针对缺失值、多粒度采样、异步多变量及图结构时空数据等更复杂场景，可进一步扩展本文提出的统一骨架与频域增强模块；针对异常检测、状态识别和决策支持等任务，也可研究预测模块与业务目标的联合优化方式，以增强模型在真实应用中的实用价值。

最后，在工程应用层面，仍有必要围绕效率与部署问题展开研究。例如，可通过模型蒸馏、量化、结构剪枝和算子融合等手段降低统一框架在训练与推理阶段的计算开销，并系统评估其在资源受限环境下的可部署性。若能够在保持精度的同时进一步降低推理时延和显存占用，本文提出的时频增强框架将在实际在线预测场景中展现出一定的应用潜力。

总体而言，本文验证了语义先验与频域增强相结合在多元长程时间序列预测中的有效性，也揭示了局部多尺度频域建模与全局频域建模在作用侧重点上的差异。未来若能沿着自适应模型选择、更强语义先验、复杂场景泛化与高效部署等方向持续推进，将有望进一步提升该类方法在理论研究和实际应用中的价值。
