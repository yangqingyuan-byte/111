\section{误差特性机理分析}

\subsection{小波包分解对大误差抑制的机理分析}

\textbf{【撰写大纲】}

1. \textbf{MSE 与大误差的关系}
\begin{itemize}
\item 回顾 MSE = \(\frac{1}{n}\sum e_i^2\)：少数\textbf{大误差}会因平方项主导整体 MSE；因此要降低 MSE，需重点\textbf{抑制大误差点}（极端预测偏差）。
\end{itemize}

2. \textbf{WPD 的机制如何作用于大误差}
\begin{itemize}
\item \textbf{多尺度分解}：小波包将信号分解到不同频段，局部突变、尖峰往往落在\textbf{高频或特定子带}中；对这些子带单独建模并参与融合，使模型能更精细地刻画“异常时刻”的时频结构，从而减少在突变处的预测偏差。
\item \textbf{门控与注意力池化}：子带编码后的门控与注意力池化（3.3 节）具有\textbf{输入依赖性}，可对“异常子带/时间步”进行选择性抑制或加强，进一步避免少数大误差点拖高整体 MSE。
\item \textbf{与实验的对应}：呼应第四章 4.3.2（MSE 优势）、4.3.3（极端波动场景下 WPD 预测更稳），形成“多尺度+选择性→大误差抑制→MSE 下降”的逻辑链。
\end{itemize}

3. \textbf{小结}
\begin{itemize}
\item 用 1 段概括：小波包通过多尺度子带与门控选择性，增强对局部突变与异常值的建模与抑制能力，从而在 \textbf{MSE} 上表现更优。
\end{itemize}

\subsection{频域前馈网络对平均误差优化的机理分析}

\textbf{【撰写大纲】}

1. \textbf{MAE 与整体误差分布的关系}
\begin{itemize}
\item 回顾 MAE = \(\frac{1}{n}\sum |e_i|\)：对所有误差一视同仁，\textbf{整体偏差的均匀降低}更能改善 MAE，而非仅针对少数大误差。
\end{itemize}

2. \textbf{FreTS 的机制如何作用于整体误差}
\begin{itemize}
\item \textbf{全局频域与可学习线性}：FFT 将信号映射到全局频域，可学习复数线性层对不同频率分量进行重组与筛选，有利于刻画\textbf{全局周期与趋势}，使预测曲线在整体上更平滑、与真实序列的“平均偏差”更小。
\item \textbf{稀疏化（SoftShrink）}：抑制小幅频域系数，相当于滤除高频噪声与细节抖动，\textbf{平滑预测轨迹}，减少全序列上的小偏差累积，从而有利于 \textbf{MAE} 的下降。
\item \textbf{与实验的对应}：呼应第五章 5.3.2（MAE 优势）、5.3.3（长期预测平滑度），形成“全局频域+稀疏平滑→整体偏差降低→MAE 下降”的逻辑链。
\end{itemize}

3. \textbf{小结}
\begin{itemize}
\item 用 1 段概括：频域前馈网络通过全局频域表示与稀疏化，强化对整体趋势与平滑性的建模，从而在 \textbf{MAE} 上表现更优。
\end{itemize}

\subsection{指标分化的理论解释}

\textbf{【撰写大纲】}

1. \textbf{统一表述}
\begin{itemize}
\item 将 6.2.1 与 6.2.2 归纳为：\textbf{MSE} 优化等价于更关注\textbf{大误差的平方}，\textbf{MAE} 优化等价于更关注\textbf{所有误差的绝对值}；因此“抑制大误差”的策略（多尺度+局部时频+选择性）更利于 MSE，“平滑整体偏差”的策略（全局频域+稀疏化）更利于 MAE。
\end{itemize}

2. \textbf{与第四、五章设计的对应}
\begin{itemize}
\item WPD：多尺度、局部子带、门控选择性 → 偏 MSE。
\item FreTS：全局频域、可学习线性、稀疏平滑 → 偏 MAE。
\item 指出二者在\textbf{优化目标上的互补性}：不存在单一模型在所有指标上同时最优，而是“按指标/场景选模型”。
\end{itemize}

3. \textbf{可选：误差分布或残差图}
\begin{itemize}
\item 若有条件，可对比 WPD 与 FreTS 在相同测试集上的\textbf{误差分布}（如直方图、分位数）或\textbf{残差时序图}，直观展示 WPD 大误差更少、FreTS 整体误差更集中等，增强说服力。
\end{itemize}

\section{计算复杂度与收敛性分析}

\subsection{计算复杂度对比}

\textbf{【撰写大纲】}

1. \textbf{复杂度来源}
\begin{itemize}
\item \textbf{WPD 模型}：小波包分解（与 level、序列长度相关）、多路子带编码（每路一个门控 Transformer + 注意力池化）、CMA 与预测头；可给出每部分的时间/空间复杂度量级（如 \(O(L)\)、\(O(L^2)\) 等），或与序列长度 \(L\)、变量数 \(N\)、子带数等的关系。
\item \textbf{FreTS 模型}：FFT/IFFT（\(O(L\log L)\)）、可学习复数线性（与通道维、频点相关）、门控编码与池化、CMA 与预测头；与 WPD 在“频域计算 vs 多路编码”上的差异可简要对比。
\end{itemize}

2. \textbf{对比结论}
\begin{itemize}
\item 用表格或文字说明：在相同 \(L_{\text{in}}\)、\(L_{\text{pred}}\)、\(N\) 下，两模型的参数量、推理时间（或 FLOPs）的相对关系；若 WPD 因多路编码更重、FreTS 因 FFT 更轻，可点出“FreTS 在复杂度上更具优势”等，为 6.4 节“在资源受限时可选 FreTS”等建议做铺垫。
\end{itemize}

\section{模型选择策略}

\subsection{基于误差敏感度的场景分类}

\textbf{【撰写大纲】}

1. \textbf{业务需求与指标对应}
\begin{itemize}
\item \textbf{更关注大误差/峰值误差}：如电力负荷尖峰、交通突发拥堵、金融极端波动等，\textbf{MSE} 或峰值误差更符合业务损失；对应地，\textbf{WPD 模型}更合适（第四、六章表明其在 MSE 上更优）。
\item \textbf{更关注整体平均偏差}：如长期趋势规划、资源总量预估、平滑指标监控等，\textbf{MAE} 或平均偏差更符合业务需求；对应地，\textbf{FreTS 模型}更合适（第五、六章表明其在 MAE 上更优）。
\item \textbf{兼顾或不确定}：可同时汇报 MSE 与 MAE，或采用加权组合；也可先按 6.1 节在目标数据集上做小规模对比，再选定主模型。
\end{itemize}

2. \textbf{数据特性与场景}
\begin{itemize}
\item \textbf{含较多尖峰、突变、局部异常}：倾向 WPD（多尺度+局部时频）。
\item \textbf{含明显全局周期、趋势平滑、噪声较多}：倾向 FreTS（全局频域+稀疏平滑）。
\item \textbf{序列较长、对推理时延或资源有约束}：可结合 6.3.1 的复杂度结论，在满足精度前提下优先考虑更轻量的模型。
\end{itemize}

3. \textbf{小结}
\begin{itemize}
\item 用 1 段或表格归纳“场景类型 → 更优指标 → 推荐模型”，便于读者按图索骥。
\end{itemize}
